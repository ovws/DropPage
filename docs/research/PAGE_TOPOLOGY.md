# Page Topology

1. **Scroll runway** — a 300vh document section supplies progress for the scene.
2. **Sticky brand scene** — full-viewport, overflow-hidden canvas with the pale-blue blueprint grid.
3. **Peripheral tile field** — eight absolute tiles interpolate from oversized off-canvas positions into an asymmetric directory grid.
4. **Center tile** — centered square that transitions paper → blue and large copy → compact OVWS mark.
5. **Profile drawer** — an OVWS-specific equivalent of the source page’s informational side surface, opened by the profile control or the center tile.

All visible motion is driven by document scroll progress. The profile drawer is the only click-driven component.
